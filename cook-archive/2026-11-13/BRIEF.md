# Brief: Mira Planner (unicorn diet planner)

Target: a colorful, playful diet planner website with the user's unicorn as mascot. It works out daily calories, makes a 7-day meal plan AND a daily exercise schedule, and works as a daily checker/tracker (tick off meals and workouts, see progress and streaks). Stack: Vite + React + Tailwind, browser storage only, no backend, no login.
Pages: landing (unicorn hero), plan wizard, Today tracker (meals + workouts checklist), weekly plan, meal detail.
References: cook/refs/R01 (unicorn.jpeg, mascot look), R02 + R04 (Buttondown hero desktop + mobile: playful illustrations flanking big chunky headline, sticker tags), R03 (Slush: black-outlined pill buttons, characters flanking a huge headline). Same quality, own style. Mascot art = user's unicorn.svg (VTracer trace of R01).
Bar (UI mapping): layout/spacing [9/10], color [9/10], typography+components [9/10], mascot fidelity vs R01 [9/10], interaction/motion [9/10], detail density [9/10]. Lighthouse accessibility >= 95 (measured).

Rules: no stock photos, meal art drawn in code. Self-hosted fonts via @fontsource allowed. Default slop ban list. Purple only as the mascot's lilac, no purple gradients.
